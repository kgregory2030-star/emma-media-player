# Emma Media Player
A free Windows media player gift from Azure Cyber Systems, Kenya. Metallic blue, silver buttons.
Plays MP4, WebM, MKV (most), MOV, MP3, M4A, WAV, OGG, FLAC and more. 10-band equalizer with presets, subtitles (.srt/.vtt), speed, rotate, screenshots, resume where you stopped.

Build: push to GitHub, open Actions > "Build Emma Media Player (Windows)" > Run workflow, download the artifact.
Run locally: npm install, npm start.
Windows may show "Windows protected your PC" because the app is not code-signed yet: More info > Run anyway.
